# 08 — UI/UX e Acessibilidade

## 8.1 Telas
- Menu Principal, Seleção de Save, Mapa-múndi, HUD em jogo, Inventário, Árvore de Talentos, Loja, Configurações, Créditos.

## 8.2 HUD (em jogo)
- Vida, stamina, fome, minimapa/radar, objetivo atual, barra de chefe, ícones de cooldown.
- Opção de ocultar HUD (foto mode).

## 8.3 Acessibilidade (Completa)
- Remapeamento total de teclas/botões.
- Legendas com tamanho/cor configuráveis; indicador de falante.
- Modo daltônico (protanopia/deuteranopia/tritanopia) com filtros.
- Alto contraste.
- Navegação completa por teclado em menus.
- Screen reader (ARIA) para menus (web).
- Escala de UI (80–150%).
- Redução de movimento (desativa screen shake).
- Opção de números de dano.
- Indicadores visuais de áudio (legendas de SFX).

## 8.4 Feedback
- Tooltips, tutoriais contextuais (primeira vez), prompts de botão por dispositivo.

## 8.5 Localização
- PT-BR + EN. Strings externalizadas em JSON; suporte a pluralização.
